# Chemica 0.7.0


## Changelog:
### Changes:
- Chemica now depends on TFMG Community Edition.
- Chemica is now shipped with Rutile.
- Updated registries to use the new CE systems.
- Tidied up Item registry.
- Engine Cylinders & Turbines are tagged properly.
- Added group tags for crystals, graded crystals & catalysts.
- All items are now tagged properly.
- Added chemical compositions to various items and fluids.
- Ingot amounts are now 90mB to match TFMG and modern mods.
- Distillation recipes now have proper durations.
- Ore crushing now produces xp and cobble.
- Altered recipe durations for crushing.

### API Changes:
- Vat Recipes:
  - Renamed `chemica:electrode` operation to `chemica:platinum_electrode`
